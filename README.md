# 📸 photo-video-manager

사진/영상을 날짜별 폴더로 정리하는 Windows 데스크톱 프로그램 (Electron)

## 주요 기능

| 기능 | 설명 |
|---|---|
| 📅 날짜 판단 | 촬영일(EXIF) → 파일명 속 날짜 → 수정일 순서 |
| 🗂️ 폴더 구조 | `연/월` 또는 `연/월/일` |
| 👀 미리보기 | 실행 전에 어디로 옮길지 표로 확인 |
| ✅ 실행 | 확인 창 → 이동, 다른 드라이브는 복사 후 검증 |
| 🔁 이름 겹침 | `파일명(1).jpg` 번호 붙이기 (덮어쓰기 없음) |
| 🗑️ 중복 정리 | 내용까지 똑같은 파일만 휴지통으로 (선택) |
| 📊 진행 표시 | 진행률, 현재/총 개수, 경과·남은 시간 |
| 📝 작업 로그 | 원본 → 대상 기록을 파일로 저장 |

## 안전 규칙

- 영구 삭제 없음 (중복 정리도 **휴지통**으로)
- 미리보기를 해야만 실행 버튼이 켜져요
- 모든 작업은 로그로 남아요

## 실행 방법

```
npm install
npm start
```

## 폴더 구조

```
photo-video-manager
├─ main.js      ← 프로그램의 뇌 (파일 읽기/이동, 창 만들기)
├─ preload.js   ← 화면과 뇌를 안전하게 이어주는 다리
├─ index.html   ← 화면 (버튼, 표, 진행률)
└─ package.json ← 프로젝트 설명서
```

## 기술 스택

- Electron
- Node.js (`fs`, `crypto`)
- [exifr](https://github.com/MikeKovarik/exifr) (사진 촬영일 읽기)
