### 0-1. C: 드라이브 휴지통 설정 확인 (검토 M1 ②)

원본 정리는 C: 같은 하드디스크에서 **휴지통**을 써요. (D:는 Windows가 USB로 인식해서 휴지통 대신 `_정리완료원본`으로 옮겨요 → 6번) 휴지통이 "바로 제거"로 설정돼 있으면 휴지통에 남지 않을 수 있어서 먼저 확인해요.

- [ ] **화면으로 확인**: 바탕화면 **휴지통 아이콘 우클릭 → 속성**
  - 위 목록에서 **로컬 디스크 (C:)** 를 고르고
  - [ ] "사용자 지정 크기"가 선택돼 있음 (최대 크기 **\_\_** MB 적어 두기)
  - [ ] "파일을 휴지통으로 이동하지 않고 삭제할 때 바로 제거"가 **체크 안 됨**
- [ ] (선택) **PowerShell로 확인** (읽기만 해요)

```powershell
Get-ChildItem 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Explorer\BitBucket\Volume' | ForEach-Object { Get-ItemProperty $_.PSPath } | Select-Object PSChildName, NukeOnDelete, MaxCapacity
```

- `NukeOnDelete`가 **1**이면 "바로 제거"(위험), **0**이거나 비어 있으면 휴지통 사용
- `PSChildName`의 `{…}` 번호가 어느 드라이브인지는 아래로 확인 (`DeviceID` 안의 같은 번호를 찾기)

```powershell
Get-CimInstance Win32_Volume | Select-Object Name, DeviceID
```

- [ ] 휴지통 최대 크기가 이번에 정리할 원본 용량보다 큰지 (작으면 먼저 넣은 원본부터 자동으로 비워져요)
