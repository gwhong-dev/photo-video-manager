# 기능 명세: 가져오기 + 변환 + 날짜 폴더 정리

> 확정일: 2026-10-13 / 대상: photo-video-manager (Electron) / 현재 버전: **v1.3** (2026-11-01 수정, 맨 아래 "변경 기록")
> 파일 이름은 다른 문서에서 가리키고 있어서 `-v1.1.md` 그대로 둠

## 화면
- 화면 1개로 통합 (기존 "폴더 정리" 기능 흡수, 탭 분리 안 함)
- 가져올 폴더 선택 / 백업 폴더 선택 (백업 폴더는 기억)
- [미리보기] → [실행] → [일시정지]
- 미리보기 표: 원본 이름 / 새 이름 / 갈 위치(🆕 새 폴더 표시) / 상태

## 파일 처리 (1개씩 끝까지)
변환 → 날짜 설정 → 저장 → 완료 표시 → 다음 파일 (원본은 처리 중 그대로 둠)

| 원본 | 결과 |
|---|---|
| HEIC | JPG (화질 92, 촬영 정보 복사, 회전 정보 정방향) |
| MOV | MP4 (영상 재압축 없이 복사, HEVC면 hvc1 태그, 소리가 MP4에 안 맞으면 AAC로) |
| JPG / PNG / MP4 등 | 변환 없이 이름만 변경 |

- 파일 이름: `YYYY-MM-DD_HHMMSS_원본이름.확장자`
- **B 규칙**: 이름 앞의 날짜가 촬영 날짜와 같으면(시간 1분 이내) 그 부분을 빼고 우리 모양으로 통일
  - `2016-08-01_17-59-31.mov` → `2016-08-01_175931.mp4`
  - `2016-08-01_17-59-31_여행.jpg` → `2016-08-01_175931_여행.jpg`
  - 날짜가 두 번 붙은 이름도 정리됨
  - 이름 속 날짜가 촬영 날짜와 다르면 앞에 붙여서 둘 다 남김
- 파일 날짜(만든 날짜/수정한 날짜): 실제 찍은 날짜
- 라이브 포토: HEIC + MOV 둘 다 저장

## 재생할 수 없는 영상 (v1.3)
- 영상은 복사·변환하기 전에 `ffprobe`로 한 번 확인 (앞쪽 정보만 읽어서 12GB도 0.1초 안에 끝남)
- `ffprobe`가 실패하거나 영상 트랙이 없으면 **⚠ 재생 불가**: 백업에 복사하지 않고, 원본을 그대로 두고, 원본 정리 대상에서 뺌. 화면(배너, 표, 끝난 뒤 안내)과 `run_` 로그에 표시
- 정리 직전에 백업에 남을 영상도 다시 확인 → 재생되지 않으면 원본을 남기고 재생 불가로 바꾸고 `clean-check_` 로그를 남김 (이 확인이 생기기 전에 백업된 손상 파일, 같은 내용의 중복을 거르려고)
- `ffprobe`를 못 찾거나 실행하지 못하면 가져오기는 계속하고 메모를 남기되, 그 영상의 원본은 정리하지 않음
- **못 찾는 손상**: 목차(`moov`)는 멀쩡한데 내용이 잘리거나 망가진 영상. 찾으려면 끝까지 읽어야 해서 큰 파일은 오래 걸림

## 날짜 찾는 순서
1. 촬영 정보 (DateTimeOriginal → CreationDate → CreateDate → DateCreated) — exiftool 사용
2. 파일 이름 속 날짜 (예: KakaoTalk_20250328_204512345) — 시간 없으면 000000
3. 둘 다 없음 → `_날짜없음` 폴더 (하위 폴더 없음, 원본 이름 유지)
- 파일 수정 날짜는 분류에 쓰지 않음 → 로그에 "참고 날짜"로만 기록

## 폴더 구조
- `백업폴더\YYYY\MM\DD` (예: `2025\03\28`), 없으면 새로 만듦
- `2025년도` 같은 후가공 폴더는 절대 안 건드림 (스캔에서 제외)
- 백업 폴더 전체를 가져올 폴더로 고를 수 없음
- 사진과 영상은 같은 날짜 폴더

## 중복 / 이름 겹침 (v1.2)
1. **내용이 같은 파일: 이름과 상관없이 크기가 같으면 지문(해시) 비교** → 같으면 완전 중복 → 건너뜀
   - 이번에 가져오는 원본끼리 (예: Windows가 복사할 때 붙인 `IMG_5267(1).JPG` = `IMG_5267.JPG`) → 앞의 것만 저장
   - 백업의 같은 날짜 폴더에 이미 있는 파일과 (변환할 HEIC·MOV는 결과가 원본과 달라서 여기서는 비교 안 함)
   - 크기가 같은 파일끼리만 계산 (전부 계산하면 느려서)
2. 새 이름이 겹치면
   - 지문(해시) 같음 → 완전 중복 → 건너뜀
   - 애플 고유 ID(PhotoIdentifier → ImageUniqueID → ContentIdentifier) 같음
     - 변환 파일(HEIC/MOV): 이미 변환해 둔 것 → 중복으로 건너뜀
     - 그 외: 같은 사진 다른 버전 → 건너뜀 + "확인 필요"
3. 둘 다 다름 → `_1`, `_2` 붙여서 저장 (이름 끝의 숫자·시각은 바꾸지 않고 항상 뒤에 붙임)
- GPS·기기 정보는 판단에 쓰지 않고 로그에 참고용으로 기록
- 같은 파일인지 확실하지 않으면(다른 경로로 본 같은 파일 등) 건너뛰고 "⚠ 확인 필요"로 표시

## 나눠서 작업 / 이어하기
- 작업 목록 파일에 파일별 상태 저장 (대기 / 완료 / 중복 / 실패 / 재생 불가 / 이미 정리됨)
- 한 번에 2,000개 (설정 가능) + 일시정지 버튼 (지금 파일까지 하고 멈춤)
- 껐다 켜면 📌 배너에서 이어서 실행
- 실행 전 백업 폴더 남은 공간 확인 (이번 회차 예상 용량보다 적으면 중단, 80% 넘으면 경고)

## 원본 정리 (v1.1)
- 방향: **회차마다 바로 확인 → 바로 정리** (최대 용량 = 원본 전체 + 한 회차분)
- 회차가 끝나면 🧹 원본 정리 카드 표시
  - 🔍 샘플 확인: 결과 파일 무작위 10개 (종류별로 골고루), 누르면 크게 열림, 다시 뽑기 가능
  - 원본 위치와 드라이브 종류 표시
- 드라이브별 처리 (영구 삭제 없음)
  - 하드디스크(내장/외장, 휴지통 있음) → 휴지통
  - USB 메모리·SD카드·네트워크(휴지통 없음) → `가져올 폴더\_정리완료원본`으로 이동 (폴더 구조 유지, 같은 드라이브라 공간 안 씀)
- 대상: 완료 / 중복 건너뜀 / `_날짜없음` 저장 — 결과 파일이 실제로 있는 것만
- 실패한 파일은 남겨 둠
- 휴지통 용량(드라이브의 약 5%)보다 크면 경고
- 끝나면 안내: "공간을 비우려면 휴지통 비우기" / "확인 후 _정리완료원본 폴더 직접 삭제"
- "나중에"를 누르면 배너의 🧹 원본 정리 버튼으로 언제든 다시
