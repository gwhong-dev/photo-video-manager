## 원인
- **직접 원인: Windows 탐색기(explorer.exe)가 30GB 까지 커져 PC 전체의 가상 메모리가 바닥남.** 가져오기 앱(Electron)은 1~2GB 수준이었어요.
- 계기 후보 (사용자 확인: 그날 밤 "2026_아이클라우드 속성" 창이 열려 있었음):
  가져올 폴더의 **속성 창(파일 수 · 크기를 세는 탐색기 창)** 이 열린 채로 그 폴더 안에서 파일 수만 개가 읽히고 휴지통으로 옮겨짐
- 재현 시험 (탐색기 메모리 변화). 셋 다 **속성 창 없이** 해서 커지지 않았어요:
  - 앱과 같은 방법(shell.trashItem)으로 작은 파일 1,000개 휴지통 → 220MB → 229MB
  - G: 휴지통 1,506개 비우기 (Clear-RecycleBin) → 221MB → 221MB
  - G: 시험 폴더를 탐색기 창으로 열어 둔 채 실제 사진 960개 넣고 휴지통 → 228MB → 248MB
  - 속성 창을 연 상태 · 1만 개 규모 시험은 사용자 요청으로 미룸 (옮기기 먼저)
- 감시 쪽 결함: 감시 프로그램이 Claude 앱과 같은 묶음으로 켜져 있어 같이 꺼졌고, "3분 대답 없음 → 앱 다시 켜기"가 메모리 부족으로 느려진 앱을 끄려 했음

## 정한 것
- 가져오기 앱에 **PC 메모리 지키기** (`lib/memory-guard.js`): 실행 · 원본 정리 시작 전과 실행 중 1분마다 남은 가상 메모리 · 탐색기 메모리를 재서, 남은 가상 메모리 3GB 미만 또는 탐색기 4GB 초과면 처리 중인 파일까지만 하고 멈춤 + 안내 ("탐색기 창 · 속성 창 닫기 또는 Windows 탐색기 다시 시작"). 원본 정리도 시작하지 않음
- 실행 확인 창에 "실행하는 동안 가져올 폴더 · 백업 폴더의 탐색기 창과 속성 창은 닫아 두세요" 안내
- 측정에 실패하면(시간 초과 · 오류) "못 잰 것"으로 보고 막지 않아요 (측정 문제로 앱을 못 쓰게 되지 않게)
- 원본 정리는 시작 전에 한 번만 재요. 정리하는 동안에는 재지 않아요 (lib/cleaner.js 는 L 이라 나중에). 그날 밤 탐색기는 04:45 에 이미 27GB 라서 시작 전 검사만으로도 막혔을 거예요
- 나머지 약 5.8만 개는 **사용자가 1만 개씩 직접** 돌림 (이 PC 에서 한 번에 돌리는 건 하지 않기로, 2026-11-14 사용자 결정)

## 버린 안
- 탐색기를 자동으로 다시 시작: 사용자가 열어 둔 창이 말없이 닫혀서, 앱은 멈추고 안내만 하기로
- 메모리를 보지 않고 묶음 크기만 줄이기: 계기가 묶음 크기가 아니라 탐색기 쪽이라 막지 못함
