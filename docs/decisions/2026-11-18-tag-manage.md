# 태그 만들기 · 이름 바꾸기 · 지우기 + 단축키 붙이기 (2026-11-18)

## 배경
- 실사용 지적: 태그 화면에 "만들기"가 없음. 태그는 사진을 고른 뒤 붙이기 창에서 새 이름을 적어야만 생겼고, 사진이 하나도 없으면 목록에서 사라졌음
- 사용자 결정 (2026-11-18): 이번 범위 = 태그 만들기 · 이름 바꾸기 · 지우기 + 단축키로 붙이기. 끌어다 놓기는 이번에 안 함
- 지키는 것: 사진 · 영상 파일은 건드리지 않음 (DB · 기록 파일 `manual-edits.jsonl` · 로그만), 되돌리기, 손이 덜 가는 정리

## 고른 방식

### 1. 빈 태그를 남길 자리 = 새 표 `tag_names (root, name, hotkey)`
- 내가 만든 태그의 "정의". 사진이 0장이어도 남고, 폴더를 다시 읽어도 안 건드림
- 붙인 이름은 모두 여기에도 들어감 (붙일 때 같이 넣고, 켤 때 빠진 것을 채움 → 이 기능 전에 붙인 태그도 바로 바꿀 수 있음)
- 구조 버전은 올리지 않음 (다른 새 표와 같은 이유: 옛 빌드가 새 DB를 "깨짐"으로 보고 다시 만들지 않게)
- 버린 안: `manual_tags` 에 경로 없는 줄을 넣기 → 경로로 잇는 기존 규칙(복구 · 다시 읽기)이 모두 예외를 알아야 해서 버림

### 2. 이름 바꾸기 · 지우기 = 기존 되돌리기 묶음의 새 종류 (`tagRename`, `tagDelete`)
- 사진마다 "내가 붙인 태그 이름 목록"을 바꾸는 건 붙이기 · 떼기와 같음 → 같은 되돌리기 줄, 같은 기록 파일 복구를 그대로 씀
- 정의(이름 · 숫자)의 전후는 새 표 `edit_tag_defs` 와 기록 파일 줄의 `defs` 에 따로 적어서, 되돌리면 숫자까지 돌아옴
- 사진이 0장인 태그의 이름 바꾸기 · 지우기, 빈 태그 만들기, 숫자 정하기는 묶음을 만들지 않음 → 0장 묶음이 "마지막 묶음"이 되어 앞 작업의 되돌리기 버튼을 가리는 일을 막으려고
- 새 이름으로 붙였다가 되돌리면 그 빈 태그도 같이 사라짐 (오타로 만든 태그가 남지 않게). 원래 있던 태그는 사진을 다 떼도 0장으로 남음
- 같은 이름의 내 태그가 이미 있으면 "합칠까요?"를 한 번 더 물음. 합치면 겹친 사진은 이름 하나, 합친 쪽 숫자를 남김 (없으면 옛 태그 숫자를 받음)
- 앨범에서 가져온 태그(파일에서 읽은 것)는 읽기 전용: 바꾸기 · 지우기 · 숫자 대상이 아님. 같은 이름의 내 태그를 지워도 앨범 태그는 그대로

### 3. DB를 새로 만들 때 = 기록 파일의 `tagDefs` 줄
- 정의가 바뀔 때마다 그 폴더의 정의 목록 전체를 한 줄로 적음. 켤 때 폴더마다 마지막 줄만 보고 **빠진 것만 채움** (지우거나 덮어쓰지 않음)
- 평소에는 DB와 같아서 0개. DB가 깨져 새로 만들었을 때 빈 태그와 숫자가 되살아남
- 옛 빌드는 새 줄(`tagDefs`, `tagRename`, `tagDelete`)을 "읽을 수 없는 줄"로 건너뜀 (옛 빌드는 켜지 말라는 기존 주의와 같음)

### 4. 단축키
- `T` = 태그 붙이기 창, `1`~`9` = 태그 화면에서 그 숫자로 정한 태그를 바로 붙이기 (숫자 하나에 태그 하나, 다른 태그로 옮기면 앞 태그는 숫자가 빠짐)
- 갤러리 · 정보 없는 사진 화면에서 사진을 골랐을 때만 (Delete 키와 같은 조건). 입력 칸 · 고르기 칸 · 열린 창 · 메뉴, Ctrl/Alt/Shift 와 같이 누를 때, 키를 누르고 있을 때(반복)는 무시
- 한글 입력 상태에서도 되게 글자(`ㅅ`) 대신 자판 자리(`KeyT`, `Digit1`)를 먼저 봄
- **이미 모두 붙어 있으면 아무것도 안 함 (떼지 않음)**: 숫자를 두 번 누르거나 섞인 선택에서 잘못 눌러도 태그가 사라지지 않게. 붙인 것은 바로 뜨는 "되돌리기"로, 떼기는 떼기 창으로. 버린 안: 누를 때마다 붙이기 / 떼기 바꾸기(토글) → 일부만 붙은 선택에서 결과를 예측하기 어려움
- 100장 이상 고르고 숫자를 누르면 바로 붙이지 않고 이름을 적어 둔 붙이기 창을 엶 (100장 이상은 장수 확인을 한 번 더 받는 2026-11-04 규칙)
- 숫자로 붙인 뒤에도 선택은 그대로 둠 (같은 사진에 다른 숫자 태그를 이어서 붙일 수 있게)
- 정한 숫자는 왼쪽 메뉴 태그 줄 · 태그 화면 · 우클릭 메뉴("N장에 '여행' 붙이기" 오른쪽에 숫자)에 보임. 붙이기 버튼 옆에는 `T`

## 손대지 않은 것
- 끌어다 놓기로 붙이기 (사용자 결정, 이번 범위 밖)
- 숫자 정하기 자체는 되돌리기 줄에 넣지 않음 (다시 고르면 되니까)
