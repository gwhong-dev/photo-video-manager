- 화면 목록과 버리기 확인(`lib/similar-discard.js`)이 같은 줄(`similarRows`, 특징값 포함)로 묶어서 묶음이 같아요
- 버린 안: 60초 밖(예: 10분 안 · 0.90 이상)도 AI 로 잇기 → 범위가 넓어져 잘못 묶일 위험, 이번엔 안 함. AI 가 같다고 본 사진의 처음 표시를 "버림"으로 → 사용자 결정(처음엔 모두 남김)과 다름

## 4. 네트워크 · 안전 규칙
- 인터넷으로 나가는 곳은 지도(`lib/map-net.js`)와 이 모델 받기(`lib/similar-ai.js downloadModel`)뿐. 받기는 **사용자가 확인 창에서 "89MB 받기"를 누를 때만**, 메인 프로세스(`net.fetch`)에서, 정해진 주소 하나로. 보내는 내용(body · 머리글) 없음. 자동으로 다시 받지 않음
- 확인 창에 받는 곳 · 크기 · 라이선스 · 보내지 않는 것 · 걸리는 시간을 보여 줌
- 크기와 SHA-256 이 맞을 때만 임시 이름에서 진짜 이름으로 바꿈 (틀리면 임시 파일을 지우고 실패 안내)
- 로그(`ai-model_*.txt`)에는 받는 주소 · 크기 · 결과만
- 창 · 화면의 네트워크 막기(`lib/window-guard.js`)는 바꾸지 않음 (화면은 계속 인터넷에 직접 나가지 못함)
- 가져오기 중에는 특징값 만들기를 쉬어요 (지문과 같은 방식)

## 6. 검증 지적과 고친 것 (#120)
- ❌ 화면 다시 받기 ↔ 특징값 다시 시작이 끝없이 반복될 수 있음 (원본을 못 읽는 사진이 남거나 onnxruntime 을 못 불러올 때) → 하나도 못 만든 회차는 폴더 · 방식 · 진행이 그대로면 다시 돌지 않음 (지문도 같은 방식으로), 모델을 열지 못하면 다시 받거나 다시 켤 때까지 시도 안 함
- ⚠️ 모델 파일이 밖에서 깨지면 다시 받을 길이 없음 → 이번 실행에서 처음 쓸 때 SHA-256 확인, 다르면 옆 이름(.broken-)으로 치워 "받기"가 다시 보임
- ⚠️ 받다 끄면 임시 파일이 남음 · 끌 때 받기를 안 멈춤 → 끌 때 멈추고, 다음 받기 때 이 모델의 임시 파일을 치움
- ⚠️ 지문과 특징값을 같은 때 시작 → 지문이 도는 중이면 특징값은 지문 뒤에
- ⚠️ 끌 때 DB 가 닫힌 뒤 쓰기 · 묶을 때마다 특징값 28MB 복사 → 멈춘 뒤엔 쓰지 않음, 복사 없이 씀
- ⚠️ 확인 창 문구 가운뎃점 → 쉼표로. 점검 56c(임시 파일 · 깨진 모델 · 멈춤) · 56e(모델 열기 실패) · 56i(AI 로 나뉜 묶음 버리기 확인) 추가

## 8. 실사용 지적 뒤 고친 것 (2026-11-16, 새 exe 로 G: 5.5만 장)

**사용자 지적 (화면 캡처 4장)**
1. 처음 표시가 전부 "남김"이라 버릴 사진을 하나하나 눌러야 함 → 처음엔 **추천 1장만 남김, 나머지 버림**이어야 함 (남길 사진만 눌러 바꿈)
2. 다른 장면이 한 묶음: 10-25 17:20:38 피규어 두 장, 10-25 17:09:44 정류장과 표지판 앞 사람, 10-21 19:41:37 꽃 1장 + 거울 공 3장 (안경 5장은 맞음)

**원인 (G: 갤러리 DB 복사본으로 확인, 사진은 읽기만)**
- 사용자 설정 폴더에 `models` 가 없음 → AI 모델을 아직 안 받음 → 3절 "한쪽이라도 특징값이 없으면 시간만으로 이어요" 때문에 60초 안 사진이 장면과 상관없이 한 묶음
- 이 사진들(가장 최근 id 78xxx)은 지문 · 흐림 점수도 아직 없었음 (DB 복사본: 지문 53,920 · 흐림 27,920 / 사진 약 5.5만, 미리 계산은 오래된 사진부터인데 목록은 최근 묶음부터). "지문이나 흐림 점수가 없는 사진은 처음엔 남김(softIds)" 이라 **묶음 전체가 남김**, 화면에 한 번 보이면 그 표시가 고정돼서 계산이 끝나도 그대로

**실측 (모델 = #120 때 받은 같은 파일, SHA-256 일치, 썸네일에서)**

- 처음 남김(softIds)은 **지문이 없고 AI 로도 같은 장면이라고 확인하지 않은 사진만** (3초 안에 찍어 붙기만 한 사진. 특징값이 있어도 이어 찍기 사슬에서 비교되지 않았으면 남김, #121 검증 지적). 흐림 점수만 없는 사진은 지문이나 AI 로 비슷하다고 본 것이라 처음엔 버림, 추천은 정보가 다 있는 사진에서 골라요 (추천 기준 ③)
