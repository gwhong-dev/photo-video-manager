# 원본 정리 확인 수준 (2026-11-15 사용자 결정)

## 배경
1차 원본 분류(I: 복사본 6만 700개, 751GB → G: 외장 HDD)에서 시간이 이렇게 들었다.

| 단계 | 시간 | 성격 |
|---|---|---|
| 복사 · 변환 (5,000개씩 12번) | 약 14시간 (실측 50,297초) | 진짜 작업. 백업 HDD 에 4개 동시 쓰기, 초당 약 15MB |
| 원본 확인: 백업 750GB 를 처음부터 다시 읽어 지문 비교 | 약 4~5시간 | 확인 |
| 정리 직전 확인: 같은 확인(재생 확인 2만여 개 포함)을 또 함 | 수십 분 이상 | 확인 |

사용자 지적: "2~3일을 확인만 돌리는 프로그램은 아무도 안 쓴다". 확인이 전체의 25~35% 이고, 대부분 같은 파일을 여러 번 읽는 것이었다.

## 결정
1. **쓸 때 기록**: 결과 파일을 다 쓴 직후 서명(크기 · 수정 시각 · 변경 시각 · 드라이브 번호 · 파일 번호)을 작업 기록에 남긴다 (`resultSig`). 영상은 이름 바꾸기 전에 결과 파일 재생 확인을 하고 통과 여부를 남긴다 (`resultPlayable`, 재생 안 되면 실패 처리).
2. **원본 정리 확인**: 지금 서명이 기록과 같은 완료 항목은 저장할 때 계산한 지문을 믿고 다시 읽지 않는다. 내용을 고치면 수정 시각, 되돌려도 변경 시각, 지우고 다시 만들면 파일 번호가 바뀌므로 "그 뒤로 아무도 안 건드림"으로 본다 (백업 도구의 기본 비교와 같은 생각, 예: rsync 는 크기 · 수정 시각이 기본, 내용 비교는 선택).
3. **표본 검사**: 기록을 믿은 것 중 1% (최소 30, 최대 500개)는 끝까지 읽어 지문을 맞춘다. 하나라도 다르면 나머지를 전부 지문으로 확인한다 (디스크 · USB 연결 문제는 보통 여러 파일에 걸쳐 나타나 표본에 잡힘).
4. **정리 직전 확인**: 확인 창에서 통과한 원본 · 결과 파일의 서명이 그대로인지만 본다. 바뀐 것은 정리하지 않는다.
5. 서명 기록이 없는 옛 작업 기록과 `deep` 확인은 지금까지처럼 전부 지문으로 확인한다.

## 디스크 종류에 따른 차이 (2026-11-15 실측)
- 이 PC 의 백업 디스크 G: (Seagate 5TB) 와 I: (Crucial X6) 는 **exFAT**. exFAT 는 변경 시각(ctime)을 기록하지 않아 모든 파일이 같은 값으로 나온다 (실측: 1240428288 초 고정).
- 그래서 exFAT 에서는 서명이 사실상 **크기 · 수정 시각 · 파일 번호**. "같은 크기로 내용을 고치고 수정 시각을 일부러 되돌린" 파일은 서명으로 못 잡고 표본에 들 때만 잡힌다. NTFS 에서는 변경 시각이 바뀌어 잡힌다 (실측 확인).
- 이렇게 고치는 프로그램은 드물고(크기가 같아야 하고, 수정 시각을 일부러 되돌려야 함), 이 앱은 백업 파일을 그렇게 고치지 않는다.
- **결정 (사용자, 2026-11-15)**: 변경 시각이 없는 디스크(같은 드라이브의 믿는 파일 2개 이상이 모두 같은 변경 시각)는 표본을 **5% (최소 30, 최대 3,000개)** 로 늘린다. 6만 개면 약 40GB 를 더 읽어 G: 에서 5~10분 더 걸린다. 화면 · 로그에 "변경 시각을 기록하지 않는 디스크라 표본을 늘렸어요"를 남긴다.
- 버린 안: exFAT 는 전부 지문 (G: 가 다시 4~5시간), exFAT 도 1% 그대로 (가장 빠르지만 약한 서명을 그대로 믿음).

## 포기하는 것
- 쓴 지 얼마 안 돼 디스크가 서명은 그대로 두고 내용만 몰래 망가뜨린 파일 하나를 반드시 잡지는 못한다 (표본에 들면 잡히고, 걸리면 전체 확인으로 넘어감). 유일본을 정리할 때 고를 "꼼꼼히"(전체 지문)는 다음 PR (⑤).

## 버린 안
- 지금처럼 전부 다시 읽기: 안전하지만 6만 개에 4~5시간 → 사용자가 쓰지 않음.
- 표본만 (서명 비교 없이): 쓴 뒤 사람이 고친 파일을 놓칠 수 있음.
- 복사본 원본이면 확인 없이 정리: 백업 쪽 문제를 아예 못 잡음.

## 예상 효과 (이번 작업 기준)
원본 확인 4~5시간 → 파일 정보 6만 번 + 표본 500개 + 변환 중복 정보 읽기로 약 5~10분. 정리 직전 확인 수십 분 → 1~2분. 복사 14시간은 그대로 (따로 손볼 문제, 개선 13).
