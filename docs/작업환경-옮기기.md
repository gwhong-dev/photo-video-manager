# 작업 환경 옮기기 (여러 PC, 클라우드)

> 작성: 2026-11-01. 코드와 문서의 기준은 **GitHub 저장소** `gwhong-dev/photo-video-manager`이고, 폴더를 복사해서 옮기지 않아요.

## 무엇이 어디에 있나

| 내용 | GitHub | 다른 곳에서 하려면 |
|---|---|---|
| 코드, 문서, CLAUDE.md, 자동 샘플(`test/samples/auto`) | 있음 | `git clone` 또는 클라우드 세션으로 자동 |
| `node_modules` | 없음 | `npm install` |
| exiftool, ImageMagick, FFmpeg | 없음 | PC마다 설치 (아래) |
| 수동 샘플(`test/samples/manual`) | 없음 (개인 사진, 위치 정보) | 직접 복사. 없으면 해당 점검은 ⏭ |
| 실사용 테스트 사진, `%APPDATA%\photo-video-manager`의 작업 기록 | 없음 | 그 PC에서만 |
| `version/`, `참고용 파워쉘/` | 없음 | 옛 복사본과 참고 자료. 복구 코드 파일은 프로젝트 밖 안전한 곳으로 |

## 새 Windows PC

```bash
git clone https://github.com/gwhong-dev/photo-video-manager.git
```

```bash
winget install --id OliverBetz.ExifTool --exact
```

```bash
winget install --id ImageMagick.ImageMagick --exact
```

```bash
winget install --id Gyan.FFmpeg --exact
```

새 터미널을 연 뒤 프로젝트 폴더에서:

```bash
npm install
```

```bash
npm run check
```

## 클라우드 세션에서 할 수 있는 것

- 할 수 있음: 코드 수정, 문서 작업, 커밋과 푸시, 코드 검토, 계획 세우기
- 내 PC에서만 할 수 있음: 앱 화면 확인, 실제 사진 테스트, 휴지통과 USB 드라이브 동작 확인
- 이 프로그램은 Windows 전용 동작(휴지통, 드라이브 종류, 폴더 연결)을 시험해요. **main에 합치기 전 `npm run check`는 Windows PC에서 통과해야 해요**

## 이어서 작업하는 순서

1. 시작 전에 최신 받기: `git pull`
2. `PROGRESS.md` 상단에서 현재 상태와 다음 할 일 확인
3. 작업 후 커밋하고 푸시, PR 올리기 (`docs/점검-푸시-절차.md`)
4. 다른 곳에서 이어가기 전에 푸시됐는지 확인
