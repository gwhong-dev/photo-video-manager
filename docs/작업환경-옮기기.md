# 작업 환경 옮기기 (PC 2대)

> 작성: 2026-11-01, 고침: 2026-11-12. 코드와 문서의 기준은 **GitHub 저장소** `gwhong-dev/photo-video-manager`이고, 폴더를 복사해서 옮기지 않아요.
> 작업 PC 는 PC A(집 게이밍 노트북) · PC B(삼성 노트북) 2대, 둘 다 Claude 데스크톱 앱 Code 탭에서 작업해요. 규칙 원본은 `CLAUDE.md` 2절이에요.

## 무엇이 어디에 있나

| 내용 | GitHub | 다른 곳에서 하려면 |
|---|---|---|
| 코드, 문서, CLAUDE.md, 자동 샘플(`test/samples/auto`) | 있음 | 각 PC **내장 디스크**에 `git clone` (USB 를 작업 폴더로 쓰지 않음) |
| 개인 권한 설정 `.claude/settings.local.json` | 없음 | PC 마다 따로 (없어도 됨, 쓰면서 생김) |
| `node_modules` | 없음 | `npm install` |
| exiftool, ImageMagick, FFmpeg | 없음 | PC마다 설치 (아래) |
| 수동 샘플(`test/samples/manual`) | 없음 (개인 사진, 위치 정보) | 원본은 외장 SSD/USB 에 두고 필요할 때만 복사. 없으면 해당 점검은 ⏭ |
| 실사용 테스트 사진, `%APPDATA%\photo-video-manager`의 작업 기록 | 없음 | 그 PC에서만 |
| `version/`, `참고용 파워쉘/` | 없음 | 옛 복사본과 참고 자료. 복구 코드 파일은 프로젝트 밖 안전한 곳으로 |

## exe로 만들어 쓰기 (2026-11-10)

개발용 `npm start` 대신 exe로 켜서 실제로 쓸 때예요. exe = 더블클릭으로 켜는 프로그램 파일.

1. 프로젝트 폴더에서 `git pull`
2. 프로그램이 켜져 있으면 끄기
3. `scripts\build-exe.bat` 더블클릭 (처음엔 1 ~ 2분)
4. 성공 기준: 창에 `exe를 만들었어요`가 나오고, 바탕화면에 `사진 영상 정리` 바로가기가 생김

- 결과는 `release\win-unpacked` 폴더예요. exe 하나만 옮기면 켜지지 않아서 폴더째 둬요 (설치 과정 없는 폴더형). 설치판과 exe 하나짜리 휴대판은 만들지 않기로 했어요 (2026-11-10 결정)
- 설정, 갤러리 목록, 태그, 기록은 `npm start`와 같은 `%APPDATA%\photo-video-manager`를 써요. exe로 바꿔도 처음부터 다시 읽지 않아요
- exiftool, ImageMagick, FFmpeg는 예전처럼 PC에 설치된 것(PATH)을 찾아요. 따로 넣어 두려면 `%APPDATA%\photo-video-manager\tools` 폴더에 두면 그걸 먼저 써요 (폴더 모양은 `lib/tools.js`의 `candidates`)
  - `release\win-unpacked\tools`도 찾지만, exe를 다시 만들 때 `release\win-unpacked`가 통째로 지워져서 거기에는 두지 마세요
- 코드가 바뀌면 1 ~ 3을 다시 하면 돼요. 바로가기는 같은 자리를 가리켜서 그대로 써요
- exe는 Electron 공식 원본(`electron.exe`)을 이름만 바꿔 써요 (2026-11-11 결정). 이 PC는 Windows의 Smart App Control(스마트 앱 컨트롤, 서명 없는 프로그램을 막는 기능)이 켜져 있어서, electron-builder가 고쳐 새로 만든 exe는 "응용 프로그램 제어 정책이 이 파일을 차단했습니다"로 안 켜져요. 공식 원본은 Windows가 이미 아는 파일이라 켜져요
  - `npm run dist` 끝에 `scripts/use-official-electron.js`가 exe를 바꿔 넣어요. 앱 파일(`resources\app.asar`), 설정 폴더, 바로가기는 그대로예요 (점검 47g)
  - 그래서 exe 아이콘과 이름표는 Electron 기본값이고, 퓨즈(exe 안 스위치, 예: `runAsNode` 끄기)는 쓰지 않아요. 고치면 다시 새 파일이 돼서 막혀요

## 클라우드 세션은 쓰지 않아요 (2026-11-12)

- 이 프로그램은 Windows 전용 동작(휴지통, 드라이브 종류, 폴더 연결)과 앱 화면을 확인해야 해서, 작업은 PC A · PC B 의 로컬 Code 탭에서 해요
- **main에 합치기 전 `npm run check`는 Windows 에서 통과해야 해요** (로컬 PC + CI)

## 이어서 작업하는 순서 (PC A ↔ PC B)

1. 세션 시작: `git fetch` → 커밋 안 된 변경 · push 안 된 커밋 · 다른 PC 에서 하던 열린 PR 이 있으면 Claude 가 먼저 알려요 → 깨끗하면 `git pull`
2. `PROGRESS.md` 상단에서 현재 상태와 다음 할 일 확인
3. 작업 후 커밋하고 푸시, PR 올리기 (`docs/점검-푸시-절차.md`, 머지 규칙은 `CLAUDE.md` 4절)
4. 세션 끝: 덜 끝난 작업도 `wip:` 커밋 + Draft PR 로 push → 다른 PC 를 켜면 바로 이어감
5. 같은 브랜치를 두 PC 에서 동시에 고치지 않아요
