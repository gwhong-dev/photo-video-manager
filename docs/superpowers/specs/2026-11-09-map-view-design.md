# 지도 보기 설계 (단계 6-1)

> 2026-11-09 사용자 승인: 1 가 (확대 정도에 따라 묶기), 2 가 (핀 이름은 보이는 큰 묶음만, 6-2에서), 3 가 (6-1 먼저)
> 화면 기준: Figma "지도" (v0.2). 지도는 색을 빼고 숫자 핀만 또렷하게, 핀을 누르면 그 장소에서 찍은 사진이 오른쪽에 나와요

## 1. 이번에 만든 것 (6-1)
- 왼쪽 메뉴 "지도"를 켜고 지도 화면(`src/components/MapView.jsx`)을 넣음
- 위치가 있는 사진과 영상을 숫자 핀으로 묶음. 확대하면 나뉨
- 핀을 누르면 오른쪽 패널(`MapPanel.jsx`): 장수, 찍은 기간, 최근 사진 9장, "N장 갤러리에서 보기"
- 갤러리는 그 곳 사진만 보여 주고, 위에 "지도에서 고른 곳의 사진만 보여요" 줄 (지도로 돌아가기, 전체 사진 보기)
- 위쪽 연도 탭 (전체 기간, 위치가 있는 사진의 연도)
- 아래 "장소가 없는 사진 N장 → 지도에 놓으러 가기" (정보 없는 사진 화면, 위치 없음 탭)
- 지도 그림을 못 받아도 핀은 그대로 보이고 안내 한 줄

## 2. 묶는 방법 (`src/places-view.mjs`, 인터넷 안 씀)
- 세계 지도를 확대 단계별로 80 화면 점 칸으로 나누고 같은 칸의 사진을 한 묶음으로 봄
- 칸 경계에 걸쳐 핀이 겹쳐 보이지 않게, 이웃 8칸의 핀이 한 칸 크기보다 가까우면 큰 핀에 합침 (한 번만)
- 묶음의 영역 = 칸 사각형 목록. 경계 규칙은 `s < 위도 <= n`, `w <= 경도 < e` (겹치지 않음). 지도 끝 칸은 ±91, ±181까지 넓힘
- 갤러리 필터 `area = { rects, year }`를 DB가 같은 규칙으로 걸러서, 핀 숫자와 갤러리 장수가 같음 (점검 42b, 42d)
- 화면 안(조금 넉넉히)만 계산. 6만 장도 한 번에 수십 ms (점검 42f)

## 3. 데이터
- `gallery:map-points` → `[[id, 위도, 경도, 찍은 날], ...]` (위치 있음, 사라지지 않음, 이 백업 폴더만, 경로 없음)
- 화면에서 온 지도 영역은 `cleanFilter`가 숫자 칸만 남김 (최대 16칸, 연도는 정수만)
- 새 표나 DB 구조 변경 없음
